# DeviceResourcesApp

Aplicativo em React Native (Expo) desenvolvido para a atividade prática
**Acesso a Recursos Nativos do Dispositivo Móvel**.

## Objetivo

Interagir diretamente com recursos nativos do sistema operacional mobile,
solicitando permissões ao usuário e integrando o aplicativo com:

- a **galeria de fotos** do dispositivo;
- a **lista de contatos** do dispositivo.

## Status

Projeto em desenvolvimento.
